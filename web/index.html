자주 궁금한 것


이미 AI가 더 똑똑해졌다는 뜻인가요?
실험 완료만으로 개선을 주장하지 않습니다. 문제 통과, 오류, 답변 시간과 채택 여부를 함께 확인해야 합니다. 프롬프트나 실행 설정 개선과 모델 자체의 학습도 구분합니다.


내 컴퓨터를 꺼도 계속되나요?
온라인 기록은 Cloudflare에 남고, 예약된 실험은 GitHub 서버에서 실행됩니다. 페이지 자체가 AI를 실행하는 것은 아닙니다. 서버 가용량이나 서비스 한도에 따라 다음 실행이 늦어질 수 있습니다.


여기에 질문하거나 일을 맡길 수 있나요?
현재는 정해진 연구 실험을 실행하고 결과를 확인하는 기능입니다. 자유로운 질문·작업 요청 창은 아직 없습니다. 공개 방문자는 기록을 볼 수 있고, 소유자는 GitHub에서 다음 실험을 실행할 수 있습니다.


모델 학습은 어디까지 됐나요?
학습 작업 상태를 확인하고 있습니다.
모델 자체를 학습시키려면 호환 GPU와 별도 평가가 필요합니다. 학습 코드를 준비한 것만으로 성능이 향상됐다고 주장하지 않습니다.


내 컴퓨터에서 직접 실행하려면?
연결 설정이 끝난 기존 프로젝트 폴더의 터미널에서 실행하세요.
rtk proxy python -m rsi status
rtk proxy python -m rsi run --cycles 1
새 컴퓨터에서는 모델과 비공개 연결 설정이 필요합니다. 상세 설정은 한국어 사용 안내를 확인하세요.




소유자 전용 · 자동 실험 중지 / 재개
관리자 키를 가진 소유자만 조작할 수 있습니다. 재개는 대기열을 활성화하는 기능이며, 즉시 실행하려면 위의 GitHub 버튼을 사용하세요.


기존 컴퓨터의 프로젝트 폴더에서 .env 파일의 RSI_TOKEN 값입니다. 공개 GitHub 파일이나 댓글에 올리지 마세요. 입력한 키는 브라우저 저장소나 주소에 저장하지 않습니다.




카드 없이 24시간 연구하기
공개 GitHub 저장소의 무료 표준 실행기로 30분마다 실제 평가를 시도합니다. 최대 48회이며, 24시간 후 또는 한도 도달 시 기본 예약으로 돌아갑니다. 실험 사이에는 대기 시간이 있고, GitHub 상황에 따라 예약이 늦어지거나 누락될 수 있습니다.


시작 후 다음 예약부터 실행합니다. 첫 실험을 바로 시작하려면 위의 GitHub 실행 버튼을 사용하세요. 연구 종료는 추가 예약을 끄며, 진행 중인 실험은 완료될 수 있습니다.


자동 연결된 서버 주소 확인
배포 설정에서 자동으로 불러옵니다. 방문자는 수정할 필요가 없습니다.
