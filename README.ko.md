# Qwen3.5-2B 공개 실험실 · 한국어 사용 안내

**작은 AI가 개선 아이디어를 내고, 같은 문제로 기존 설정과 비교한 뒤, 더 좋은 결과만 채택하는 공개 연구 프로젝트입니다.**

[한국어 실험실 열기](https://juwonllee2024-dotcom.github.io/internet-rsi/) · [전체 코드](https://github.com/juwonllee2024-dotcom/internet-rsi) · [GitHub 실험 실행 화면](https://github.com/juwonllee2024-dotcom/internet-rsi/actions/workflows/rsi.yml)

## 처음 방문했다면

1. 실험실에서 **실제 AI 답변 살펴보기**를 누르세요.
2. 문제를 골라 **정답 / 기존 설정의 답변 / 새 설정의 답변**을 비교하세요.
3. **실험 결과**에서 통과한 문제 수와 채택 이유를 확인하세요.

결과와 예시는 로그인 없이 볼 수 있습니다. 예시는 3번째 실험의 실제 보관 기록입니다. 영문으로 실행했던 문제를 한국어로 설명하며, 문제를 고르는 동작은 새 AI 추론을 실행하지 않습니다.

`2/8 통과`는 8개 문제 중 2개를 통과했다는 뜻입니다. **채택**은 새 설정이 평가 기준을 통과했다는 뜻이고, **미채택**은 기존 설정을 유지했다는 뜻입니다. 새 설정이 기존에 풀던 문제를 하나라도 틀리면 채택하지 않습니다. 답변이 끝나지 않거나 실행 오류가 생긴 경우도 성공으로 처리하지 않습니다.

서로 다른 실험은 문제나 평가 버전이 다를 수 있으므로, 점수는 **같은 실험 안에서** 비교하세요. 한 번의 소규모 평가 결과로 AI 전체 능력이 좋아졌다고 판단할 수는 없습니다.

## 소유자가 실험을 한 번 실행하려면

1. [GitHub 실험 실행 화면](https://github.com/juwonllee2024-dotcom/internet-rsi/actions/workflows/rsi.yml)을 여세요.
2. 저장소 소유자 또는 쓰기 권한이 있는 GitHub 계정으로 로그인하세요.
3. **Run workflow**를 누르고, 브랜치는 **main**을 선택하세요.
4. 다시 **Run workflow**를 눌러 실행하세요.
5. 실행 기록의 완료 여부를 확인한 뒤, 한국어 실험실에서 **최신 결과 새로고침**을 누르세요.

실행 가능한 다음 실험을 한 번 수행합니다. 다른 실행이 작업 중이거나, 일시 중지 상태이거나, 하루 한도에 도달했다면 새 실험이 시작되지 않을 수 있습니다. 실행 상태와 평가 결과는 별개입니다. GitHub 실행이 완료되어도 새 설정이 미채택될 수 있습니다.

예약 실행은 6시간 간격입니다. 온라인 완료 실험은 서버 날짜(UTC) 기준 하루 최대 4회로 제한합니다. 실제 시작 시간은 GitHub의 예약 실행 사정에 따라 늦어질 수 있습니다.

## 일시 중지와 재개

실험실 아래 **소유자 전용 · 자동 실험 중지 / 재개**를 펼치고 관리자 키를 입력하면 일시 중지·재개할 수 있습니다. 관리자 키는 이 프로젝트의 로컬 `.env`에 설정된 `RSI_TOKEN`입니다. 공개 코드, 댓글, 스크린샷에 키를 올리지 마세요.

입력한 키는 브라우저 저장소에 저장하지 않습니다. **입력한 키 지우기** 버튼으로 현재 화면에서 지울 수 있습니다. 재개 버튼은 실행을 허용하는 기능이며, 실제 추론은 다음 예약 실행 또는 GitHub 수동 실행에서 시작합니다. 일시 중지는 새 실험 시작을 막고, 이미 진행 중인 실험은 완료될 수 있습니다.

## 내 컴퓨터가 꺼져도 되나요?

네. 연구 상태는 Cloudflare에, 예약된 실험 실행은 GitHub 서버에 있습니다. 인터넷에 저장된 기록은 컴퓨터를 꺼도 남습니다. 실제 실행은 해당 서비스의 사용 한도와 가용성에 따라 이루어집니다.

현재 사이트는 **연구 상황과 실제 답변을 보는 실험실**입니다. 방문자가 자유롭게 질문하는 채팅 서비스나 일반 작업을 맡기는 서비스는 아직 제공하지 않습니다.

## 무엇을 개선하나요?

현재 Qwen3.5-2B의 답변 지시와 생각하기 설정을 비교합니다. 같은 실험에서 산술, 지시 따르기, 코드, 계획, 계산 도구, 기억 도구 등을 평가합니다. 새 설정의 점수와 답변 시간을 측정하고, 오류와 기존 문제의 성능 저하를 확인한 뒤 채택 여부를 결정합니다.

추가 학습(LoRA) 준비 코드는 별도로 있습니다. 현재 확보된 컴퓨터에 필요한 GPU가 없어 해당 작업은 대기 중이며, 추가 학습 성공이나 모델 가중치의 개선은 검증되지 않았습니다. 초기 공개 실험 3회에서는 변경이 모두 미채택되어 기준 버전 v1을 유지했습니다. 이후 상황은 실험실의 최신 기록으로 확인하세요.

## 로컬 컴퓨터에서 확인하기 · 고급 사용

프로젝트 폴더에서 PowerShell을 열어 실행합니다. 이 프로젝트는 RTK를 통해 명령을 실행합니다.

```powershell
rtk proxy python -m rsi status
```

이 명령은 현재 연구 상태만 확인합니다. 실제 실험을 한 번 실행하려면 Ollama와 `qwen3.5:2b-q4_K_M` 모델이 준비되어 있어야 합니다.

```powershell
rtk proxy python -m rsi run --cycles 1
```

로컬 실행은 내 컴퓨터의 CPU와 메모리를 사용합니다. 한 번에 하나의 추론, CPU 스레드 4개, 제한된 출력 길이를 사용하며, 사용 가능한 메모리가 5GiB 미만이면 실행을 막습니다. `.env`의 온라인 연결 설정이 있으면 같은 연구 기록에 결과를 저장합니다.

```powershell
rtk proxy python -m rsi pause
rtk proxy python -m rsi resume
```

## GitHub에서 내용을 수정할 수 있나요?

네. 저장소 쓰기 권한이 있으면 파일을 수정할 수 있습니다. `web/` 아래 화면 파일을 `main`에 반영하면 GitHub Pages가 자동 배포합니다. 코드 변경에는 자동 검사가 실행됩니다. Cloudflare 서버 코드 변경은 별도의 Worker 배포가 필요합니다.

화면 예시는 `artifacts/cycle-3.json`의 실제 기록에서 만들었습니다. 예시 데이터를 다시 만들 때는 다음 명령을 사용합니다.

```powershell
rtk proxy python scripts/build_examples.py
```
